# No-Code / Low-Code Stack

## Target architecture

### AI
Use a production-capable LLM provider for parsing, reasoning, drafting, extraction, and structured outputs.

### Data
Use a managed relational database with authentication and row-level access controls.

### Workflow
Use a visual workflow orchestrator for triggers, AI calls, database operations, notifications, and approval steps.

### Interface
Use an AI-assisted application builder so the UI and CRUD flows can be generated from natural-language requirements.

### Portfolio
Use GitHub for product documentation, schemas, prompts, workflow definitions, decision records, and synthetic demonstrations.

### Browser automation
Add only for workflows that genuinely require interacting with external application sites. Keep a mandatory approval checkpoint before submission.

## Operating principle

The goal is for the product owner to configure and operate the system without writing application code.

## Security

Never commit:

- API keys
- session cookies
- passwords
- private resumes
- identity documents
- recruiter/private communication
- production database credentials
