# JD Analysis Workflow

1. Capture job input.
2. Normalize source text.
3. Parse the job into structured requirements.
4. Classify MUST / SHOULD / NICE.
5. Retrieve candidate evidence.
6. Run requirement-to-evidence matching.
7. Generate fitment output.
8. Generate gaps and follow-up questions.
9. Store the analysis.
10. Present the result to the user.
