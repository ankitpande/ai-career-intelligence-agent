# Claim Traceability

Every important factual output should be explainable.

## Minimum trace

Output claim
-> evidence record
-> evidence status
-> source
-> transformation / reasoning note

## Example

Claim:
"Led a product roadmap across multiple workstreams."

Trace:
- Evidence record: SYNTH-ACH-001
- Status: USER_CONFIRMED
- Source: private evidence bank
- Transformation: concise resume wording
- Used in: synthetic resume version example

Public examples should use synthetic data.
