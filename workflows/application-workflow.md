# Application Workflow

1. Select target job.
2. Confirm the job analysis.
3. Select or create a tailored resume version.
4. Generate form fields and answers.
5. Mark uncertain answers for confirmation.
6. Human reviews the completed application.
7. Browser layer fills and validates fields.
8. Browser layer stops before final submission.
9. Human explicitly approves submission.
10. Submit and write an audit record.
