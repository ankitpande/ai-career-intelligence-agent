# JD Parser Prompt Contract

## Input

Unstructured job content.

## Output

Return structured fields for:

- company
- role
- seniority
- location
- work_model
- function
- industry
- reporting
- experience
- education
- technical_requirements
- functional_requirements
- leadership_requirements
- domain_requirements
- responsibilities
- expected_outcomes
- technology
- AI_GenAI
- product
- analytics
- commercial
- PnL
- people_leadership
- travel
- compensation
- deadline
- contacts
- application_url
- source
- captured_at

## Classification

Each requirement should be classified as:

- MUST
- SHOULD
- NICE

Never infer a requirement solely from a familiar title.
